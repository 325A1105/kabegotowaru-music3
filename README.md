# 壁ごと割る

YOUR NAME

詳しい手順は同梱の「使い方.txt」を開いてください。

1. ZIPを解凍し、中身を自分のGitHubリポジトリ直下へアップロードしてください。assetsフォルダも必要です。
2. https://vercel.com/new で自分のGitHubを連携し、リポジトリをImportしてください。
3. Framework Preset: Other / Build Command: 空欄 / Output Directory: .
4. Deploy後、再生ボタンを押すと音楽を再生できます。

ビルド・APIキーは不要です。音源は assets/track.mp3、画像は assets/artwork.jpg です。
素材はサイト公開とともに取得できる状態になります。公開できる素材を使用してください。
